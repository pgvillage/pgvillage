# azure

Inventory to deploy PgVillage on Azure: Rocky Linux EL-9 on AMD64, with a VMSS of 3 database hosts, a bastion host,
a Load Balancer VIP and backups to an Azure Storage container.

See the [Azure docs](../../docs/administrators-guide/platforms/azure/index.md) for how to use it, and for the changes
to deploy on [openSUSE](../../docs/administrators-guide/platforms/azure/el-vs-suse.md) or
[ARM64](../../docs/administrators-guide/platforms/azure/amd-vs-arm.md).
