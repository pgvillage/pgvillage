    Vagrant - creating the boxes¶

    The Vagrantfile uses local boxes: nibble/ubuntu-26.04, nibble/rocky-9 and nibble/suse-16 (see Other operating systems). They are public boxes with the VirtualBox guest additions added, which the shared folders need. You create them once, and only the one for the OS you use.

    The steps work on amd64 and on aarch64 (Apple silicon). The only difference is the guest additions installer: VBoxLinuxAdditions-arm64.run on aarch64, VBoxLinuxAdditions.run on amd64.

    Use recent guest additions: the kernel modules must build against the (updated) kernel of the box. With VirtualBox 7.2.4, the guest additions it ships fail to build on Rocky Linux 9.8 (implicit declaration of function 'from_timer'); those of 7.2.22 build fine. Update VirtualBox, or download only the guest additions ISO of the latest release (https://download.virtualbox.org/virtualbox/<version>/VBoxGuestAdditions_<version>.iso, see LATEST.TXT in that folder) and attach that one instead. Guest additions newer than VirtualBox itself work.

    All boxes start the same way:

    1. Go to a new folder: cd $(mktemp -d).
    2. Create a vagrant VM from the public box (see below) with vagrant init <box>, start it with vagrant up and log in with vagrant ssh.

    And end the same way:

    1. (optionally) Add your modifications to /etc/motd.
    2. Clear the machine id, so every VM made from the box gets its own: sudo truncate -s 0 /etc/machine-id.
    3. Clear the history: history -c && history -w.
    4. Stop the VM: vagrant halt.
    5. Package the box: vagrant package --output <name>.box.
    6. Add the box to the local registry: vagrant box add <name>.box --name <box name> (add --force to replace a box you made before).

    Tip

    The deploy updates all packages on the boxes. That is quick on a box with all updates in it, so rebuild the box now and then.

    Instead of adding the guest additions ISO in the VirtualBox GUI, you can attach it with VBoxManage while the VM is stopped (the VM id is in .vagrant/machines/default/virtualbox/id, and VBoxManage showvminfo <id> shows the storage controller):

    VBoxManage storageattach $(cat .vagrant/machines/default/virtualbox/id) --storagectl "VirtIO Controller" \
  --port 1 --device 0 --type dvddrive --medium /Applications/VirtualBox.app/Contents/MacOS/VBoxGuestAdditions.iso

    Use --medium none to remove it again before packaging. The ISO path is for macOS.

    If you have the vagrant-vbguest plugin, it tries to install the guest additions on vagrant up and may fail ("An error occurred during installation of VirtualBox Guest Additions"). Ignore it and install them as described below.

    Ubuntu box¶

    Based on cloud-image/ubuntu-26.04, box version 20260421.0.0.

    1. vagrant init cloud-image/ubuntu-26.04 --box-version 20260421.0.0, vagrant up and vagrant ssh.
    2. Update the packages. full-upgrade, because upgrade holds back the new kernel: 
      sudo apt-get update && sudo apt-get full-upgrade -y && sudo apt-get autoremove --purge -y
    3. Stop the VM: vagrant halt.
    4. In VirtualBox (the GUI) go to the VM, Settings, Storage, click the CD-ROM with the +, select VBoxGuestAdditions.iso, click Choose and click OK.
    5. Start the VM and log in again: vagrant up and vagrant ssh.
    6. Install the guest additions: 
      sudo mount /dev/cdrom /mnt/
cd /mnt/ && sudo ./VBoxLinuxAdditions-arm64.run   # VBoxLinuxAdditions.run on amd64
      On kernel 7.0 the display driver (vboxvideo) fails to build. The boxes have no display, so that is fine: what matters is that lsmod | grep vbox shows vboxguest and vboxsf (the shared folders).
    7. Restart the VM so VirtualBox finishes setting up the guest additions: vagrant reload.
    8. Disable cloud-init, and clean the package cache: 
      sudo touch /etc/cloud/cloud-init.disabled
sudo apt-get clean
      cloud-init has done its job (it created the vagrant user) when you build the box. Left on, it runs on every boot without data from VirtualBox, configures DHCP on the private network, and then waits 2 minutes for that network to come online. The network config it wrote for the NAT interface stays, and scripts/set_ip.sh configures the private network.
    9. Finish as above, with vagrant package --output nibble-ubuntu.box and vagrant box add nibble-ubuntu.box --name nibble/ubuntu-26.04.

    Rocky Linux box¶

    Based on bento/rockylinux-9.

    1. vagrant init bento/rockylinux-9, vagrant up and vagrant ssh.
    2. Update the packages and install what the guest additions need to build: 
      sudo dnf update -y
sudo dnf install epel-release -y
sudo dnf install dkms gcc make kernel-devel bzip2 binutils patch libgomp glibc-headers glibc-devel -y
    3. Stop the VM, add VBoxGuestAdditions.iso and install the guest additions, as in steps 3 to 7 of the Ubuntu box. The update installs a new kernel (Rocky 9.8), and the VM boots it in step 5, so the guest additions build for that kernel (see the note on recent guest additions above). Check with lsmod | grep vbox that vboxguest and vboxsf are loaded. Clean the package cache: sudo dnf clean all.
    4. Finish as above, with vagrant package --output nibble-rocky-9.box and vagrant box add nibble-rocky-9.box --name nibble/rocky-9.

    openSUSE box¶

    Based on bento/opensuse-leap-16.0.

    Note

    The PostgreSQL community has no aarch64 packages for SUSE: on aarch64 you need PostgreSQL packages from another source, see SUSE.

    1. vagrant init bento/opensuse-leap-16.0, vagrant up and vagrant ssh.
    2. Update the packages: sudo zypper update -y.
    3. Stop the VM: vagrant halt.
    4. In VirtualBox (the GUI) add VBoxGuestAdditions.iso to the VM, as in step 4 of the Ubuntu box.
    5. Start the VM and log in again: vagrant up and vagrant ssh. It installs the guest additions by itself (and probably finishes updating packages).
    6. Install what the guest additions need, and avahi: 
      sudo zypper install -y gcc make dkms kernel-default-devel patch binutils avahi
sudo systemctl enable --now avahi-daemon
    7. Give root sudo permissions: 
      sudo bash -c 'echo "root ALL=(ALL) NOPASSWD: ALL" >> /etc/sudoers'
    8. Finish as above, with vagrant package --output nibble-suse-16.box and vagrant box add nibble-suse-16.box --name nibble/suse-16.

    Other boxes¶

    Any box with the VirtualBox guest additions works. Use its name with PGV_BOX, together with the PGV_OS that matches its OS:

    PGV_OS=el PGV_BOX=my/almalinux-9 vagrant up
