# Roles

The reference of every role (its variables, their defaults and descriptions) will be generated here from
`defaults/main.yml` of the role versions in `requirements.yml`. Until then, see `defaults/main.yml` in the repository of
each role, e.g. [ansible-role-stolon](https://github.com/pgvillage/ansible-role-stolon/blob/main/defaults/main.yml).
